# YOLO Pose 训练参数说明

## ⚠️ 重要提示

### 1. `lr_scheduler` 参数

**问题**: `lr_scheduler` 不是有效的YOLO训练参数

**解决方案**: 
- Ultralytics YOLO 使用 `lrf` 参数来控制学习率衰减
- `lrf` 表示最终学习率比例（最终学习率 = lr0 * lrf）
- 例如：`lr0=0.01, lrf=0.01` 表示学习率从0.01衰减到0.0001

**示例配置**:
```yaml
training:
  lr0: 0.01      # 初始学习率
  lrf: 0.01      # 最终学习率比例（0.01 * 0.01 = 0.0001）
```

### 2. `kpt_shape` 参数

**问题**: `kpt_shape` 不是训练参数，不能作为训练配置传递

**解决方案**: 
- `kpt_shape` 应该在**数据配置文件**（`data.yaml`）中定义
- 格式: `kpt_shape: [关键点数量, 维度]`
- 例如：`kpt_shape: [17, 3]` 表示17个关键点，每个关键点有3个值(x, y, visibility)

**正确的配置方式**:

在 `data.yaml` 中:
```yaml
train: ./train/images
val: ./valid/images

# 关键点配置（必须在这里定义）
kpt_shape: [4, 3]  # 4个关键点，每个关键点3个值
flip_idx: [0, 1, 2, 3]  # 翻转时关键点的对应关系

nc: 1
names: ['person']
```

**不要在 `train_config.yaml` 中定义 `kpt_shape`**，因为训练脚本不会读取它。

## ✅ 有效的训练参数

以下参数是有效的，可以在 `train_config.yaml` 中使用：

### 模型参数
- `model`: 模型路径或名称
- `pretrained`: 是否使用预训练权重

### 数据参数
- `data`: 数据配置文件路径
- `imgsz`: 图像尺寸
- `batch`: 批次大小
- `workers`: 工作进程数
- `rect`: 矩形训练
- `multi_scale`: 多尺度训练

### 训练参数
- `epochs`: 训练轮数
- `optimizer`: 优化器类型（SGD, Adam, AdamW等）
- `lr0`: 初始学习率
- `lrf`: 最终学习率比例（**不是lr_scheduler**）
- `momentum`: 动量
- `weight_decay`: 权重衰减
- `warmup_epochs`: 预热轮数
- `patience`: 早停耐心值
- `amp`: 半精度训练

### 损失函数参数
- `box`: 边界框损失权重
- `cls`: 类别损失权重
- `pose`: 关键点损失权重
- `dfl`: DFL损失权重
- `kobj`: 关键点可见性损失权重

### 输出参数
- `project`: 项目输出路径
- `name`: 训练运行名称
- `exist_ok`: 是否覆盖已有输出

## 📝 配置示例

### 正确的训练配置文件 (`train_config.yaml`)

```yaml
model:
  path: "yolov8n-pose.pt"

data:
  config: "/path/to/data.yaml"
  imgsz: 640
  batch: 16

training:
  epochs: 300
  optimizer: "SGD"
  lr0: 0.01
  lrf: 0.01  # 学习率衰减，不是lr_scheduler
  patience: 50
  amp: true

loss:
  box: 7.5
  cls: 0.5
  pose: 12.0
  dfl: 1.5
  kobj: 1.0

output:
  project: "./runs/train"
  name: "yolov8n-pose"
```

### 正确的数据配置文件 (`data.yaml`)

```yaml
train: ./train/images
val: ./valid/images

# 关键点配置（必须在这里定义）
kpt_shape: [4, 3]  # 4个关键点
flip_idx: [0, 1, 2, 3]

nc: 1
names: ['person']
```

## 🔍 如何查看所有有效参数

运行以下命令查看Ultralytics YOLO支持的所有参数：

```bash
yolo cfg
```

或者查看官方文档：
https://docs.ultralytics.com/usage/cfg

## ❓ 常见错误

### 错误1: `'lr_scheduler' is not a valid YOLO argument`
**原因**: 使用了不存在的参数名
**解决**: 使用 `lrf` 参数代替，或移除该参数

### 错误2: `'kpt_shape' is not a valid YOLO argument`
**原因**: 在训练配置中定义了 `kpt_shape`
**解决**: 将 `kpt_shape` 移到数据配置文件（`data.yaml`）中

### 错误3: 参数不生效
**原因**: 参数名拼写错误或不是有效参数
**解决**: 检查参数名是否正确，参考官方文档

---

**记住**: 
- `kpt_shape` → 在 `data.yaml` 中定义
- `lr_scheduler` → 不存在，使用 `lrf` 代替
- 不确定的参数 → 运行 `yolo cfg` 查看
